# Read Me
This is my fork of Farhan's ZBitx Front Panel code. My main goal is to implement a shutdown function for the ZBitx so that unplugging it will not jeapordize the SD card conents.

I am also adding the User_Setup.h file that is required for communication with the display and the touch screen. Please copy that file into your Arduino/Library/TFT_eSPI folder.
